## About this entry

The line is a museum label from the year 3000, which is exactly the
format the bounty asks for. It opens with the catalogue line,
"Wi-Fi Router, Earth, c. 2025.", so the reader is standing in a
gallery before the joke even starts. Then the label explains the
object with full curatorial deadpan: humans worshipped this blinking
box nightly, whispering "please work" before every important call.
That is the whole joke, a future civilisation treating a
temperamental plastic box as a sacred object, because to them that is
exactly what it was. The laugh comes from the whispered prayer, a
detail every reader recognises from their own life with a router.
The line is a single sentence, it needs no explanation, and it stays
well inside the two hundred character cap. The program holds the
line, checks it against that cap, and writes it to /output/entry.txt
exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
